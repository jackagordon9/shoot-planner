# Hudler Homes Shoot Planner

Mobile-first shoot planner for Hudler Homes lifestyle and branding photo shoots: itinerary with spots and map links, visual shot list, shoot mode, packing list, pose and location library, PDF export, and zip backups.

Live app: https://jackagordon9.github.io/shoot-planner/

On iPhone: open the link in Safari → Share → Add to Home Screen. Data is stored on each device inside the app (not in this repository). Keep backups via Settings → Download backup.
